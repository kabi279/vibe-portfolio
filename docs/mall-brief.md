# 会员权益商城 — 产品 Brief

## 目标用户（分层画像）

**第一类：高频出行会员（商旅人士/周末家庭）**
- 特征：出差或家庭出游频繁，积分积累快，但消耗渠道少。
- 核心诉求：高效使用积分兑换机场贵宾厅、接送机、酒店升级等即时出行权益。

**第二类：学生/年轻用户（积分敏感型）**
- 特征：时间灵活但消费预算有限，乐于通过签到、任务等轻量方式积攒积分。
- 核心诉求：希望用碎片化积分兑换低门槛、高频次的数字权益（视频会员、话费）或生活好物（纸巾、背包），追求“薅羊毛”的满足感。

## 核心痛点
- **价值感知弱**：用户不清楚积分能换什么，尤其是学生群体觉得积分增长慢、兑换门槛高。
- **场景错配**：权益商品偏出行场景，对非差旅用户（如学生）吸引力不足，缺少生活化权益。
- **流程冰冷**：兑换流程缺乏即时反馈，用户不清楚等级特权差异。

## 产品价值
- **场景拓宽**：整合“出行权益（贵宾厅/接送机）+ 异业合作商品（视频会员/话费/生活好物）”，覆盖高频出行与日常消费双场景。
- **等级激励**：通过会员等级（银/金/铂金）区分权益折扣、专属商品及兑换门槛，强化成长感。
- **即时满足**：打通签到、任务、积分抵扣与模拟兑换闭环，让用户实时感知积分价值。

## 会员等级分层机制（运营核心）
- **银卡（默认）**：可兑换基础权益和部分异业商品（如纸巾、7折视频券），签到积分正常累积。
- **金卡（累计成长值解锁）**：享有积分兑换专属折扣（如9折兑换话费），解锁部分高端出行权益（如快速安检）。
- **铂金卡（高成长值）**：享有积分兑换专属折扣（如8.5折），解锁限量商品库存（如登山包、机场贵宾厅），兑换流程带有专属标识及优先模拟处理。

## 商品分类与数据范围（含异业合作）
商品池规划为以下三类（初期本地写死8-10个商品，覆盖各类别）：

1. **出行服务类**：机场贵宾厅体验券、接送机优惠券、酒店升房券。
2. **数字权益类（异业合作）**：爱奇艺/腾讯视频VIP周卡/月卡、话费充值券（如10元话费）、外卖会员红包。
3. **生活好物类（异业合作）**：品牌纸巾组合包、便携登山包、定制雨伞、保温杯等实物商品（模拟兑换，不涉及真实物流）。

> 注：实物商品在Demo中仅做展示与模拟兑换成功页呈现，不接入真实物流系统。

## 主用户路径（核心操作流）
1. 进入商城首页 → 查看当前会员等级（银/金/铂金）及可用积分。
2. 通过分类筛选（出行/数字权益/生活好物）浏览商品 → 点击进入详情页查看兑换条件及等级限制。
3. 加购或立即兑换 → 进入购物车/结算页。
4. 系统自动计算可用积分抵扣、匹配可用优惠券。
5. 提交模拟兑换 → 展示兑换成功页（含订单号及等级专属标识）。
6. 返回会员中心查看成长值进度、优惠券及模拟订单记录。

**简写路径**：
首页 → 商品列表（分类筛选） → 详情页 → 加购 → 购物车 → 结算（积分/优惠券抵扣） → 成功页

## 关键指标（埋点事件）
- `view_item`：浏览商品详情（携带等级、商品分类）
- `add_to_cart`：加入购物车
- `begin_checkout`：进入结算
- `redeem_success`：兑换成功（携带等级、消耗积分值）
- `view_member_center`：查看会员中心

## 本期明确不做（边界）
- 真实支付（微信/支付宝/银联）
- 用户登录/注册（无账号体系，基于本地设备ID或手动选择等级测试）
- 后台管理系统（商品数据直接写在 `mallData.js` 中）
- 地图或 LBS 定位服务
- 真实物流/发货跟踪（实物商品仅停留于兑换成功页）
- 真实大模型 API 调用
